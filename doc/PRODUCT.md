# 产品说明

> 状态：产品范围与实测记录以 [ROADMAP.md](ROADMAP.md) 为准。已实现的首版边界保持如下；未完成验收项单独列明。

## 产品定位

**CaretLex：Vocabulary that lives in your Markdown.** 它是面向英语学习者的本地 Markdown 阅读软件，界面使用简体中文。用户阅读英文时选取生词，将原型、中文翻译和原句存入**同一篇文档**的词条脚注。复制文档即可携带词条，git diff 可看到存词操作。应用不依赖词条数据库或云账户；可同步的应用设置也使用本地 JSON 文本文件。

目标用户是使用 Obsidian、Logseq、VS Code 或 git 管理英文笔记、重视纯文本与迁移能力的读者。首版首先把“阅读→选词→手动释义→存入原文→再次阅读时回看”做完整，不承担通用 Typora 式编辑器的目标。

## 首版用户流程

1. 用户新建或打开 `.md`，以阅读模式查看 CommonMark 与 GFM 内容，包括普通脚注、表格、任务列表和代码高亮。多篇文档可在标签页间切换；相对图片按文档位置读取，外部链接由系统浏览器打开。
2. 用户在段落、标题、列表、引用、表格或加粗/斜体文本中选中**一个英文单词**。工具条打开手动 provider 的录入卡。代码、链接文字、原始 HTML、多词和跨节点选择不提供首版存词能力；无法精确映射到源码的单词也会说明原因并禁用保存。
3. 卡片预填选中词形作为 lemma 建议，用户确认或改成原型；例如把 `went` 改为 `go`。应用从可见文本提取包含选词的当前句，无法可靠分句时取当前文本块，原句在保存前可编辑。首版不使用 ECDICT 或其他自动词形还原。
4. 默认录入表单要求 lemma 和非空中文翻译，原句可空；默认生成 `word`、`translation`、`example` 三字段对象。使用自定义设置时，卡片改为原始 JSON 编辑器，接受任意合法 JSON 值，并在保存前显示最终内容。设置模板只影响之后创建的词条，不自动迁移旧定义。
5. 点击“存为词条”后，应用立即对原文件做定点写入。新 lemma 建立定义和引用；已有 lemma 在新位置只加同标签引用，翻译和首次原句不自动改动；已经标记的位置重复操作不写入。读取视图随即更新。
6. 词条锚点以中性虚线下划线呈现，悬停约 300ms 显示 lemma、可用的翻译和原句；可展开完整 JSON。卡片提供显式编辑和删除。删除托管词条时移除其定义及所有正文引用，原文词形保留。

## 文档与设置操作

- 提供新建、打开、保存、另存为、多标签、阅读/源码切换、设置和当前文档导出。CodeMirror 6 源码编辑由用户显式保存；标签页和切换模式必须处理未保存草稿，切回阅读前选择保存或放弃。
- 外部编辑器修改磁盘文件时，无草稿的标签页重新解析；本应用有待保存内容或即将存词时，比较版本并阻止覆盖，保留草稿及冲突提示。不能为了继续操作而默默覆盖外部修改。
- 设置页可把 UTF-8 JSON 设置文件迁移到用户指定的同步目录；应用仅在本机保留启动时定位该文件的路径。设置页首版编辑 JSON 模板和字段来源映射，树状可视化构建器留待后续。
- “导出 JSON”按钮只把当前文档**托管区块内**的合法词条输出为单行 `lemma → 原 JSON 值` 对象。不做 CSV、Anki、文件夹扫描或 Markdown 单词本转换。
- 亮色与暗色主题均在首版提供，默认跟随系统并允许手动切换；颜色和 Logo 规则见 [BRANDING.md](BRANDING.md)。不显示 `new/learning/known`、添加次数或复习排期。

## 首版完成的判据

可在 Linux x64 安装包中打开含普通脚注与词条的英文文档，完成一次新词保存、同词另一位置保存、悬停回看、编辑、删除、源码修改和 JSON 导出；关闭后重新打开，结果仍由 Markdown 自身重建。验证存词前后 diff 时，除选定位置的引用和托管区块之外没有变动。损坏 JSON、重复定义、外部修改或无法准确定位的选区不得导致悄然丢失内容。

外部 GFM 阅读器把词条显示为可点击的普通脚注编号及文末 JSON，是已接受的降级显示。首版仅处理英文阅读和中文界面；短语、其他阅读语言、词典接入、状态管理、文件树、大纲与所见即所得编辑均列入 [未完成事项](ROADMAP.md)。
