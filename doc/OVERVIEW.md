# CaretLex 项目概览

> 状态：首版核心协议、阅读与源码编辑界面已实现；Linux x64 AppImage 和使用 `example.invalid` 元数据的测试 deb 均已构建。测试 deb 不可发行或分发，真实发行元数据、系统安装和部分人工验收仍未完成；详见 [实施记录](ROADMAP.md)。本文档集保留 2026-09-23 访谈后确认的产品决定。

CaretLex 是面向**英文 Markdown 阅读**的软件，界面使用简体中文。读者在原文中选词，手动确认原型并填写中文翻译；词条作为标准 Markdown 脚注保存在同一篇文档里。文档和设置都保存在本地文本文件中，不需要云服务或词条数据库。

## 当前交付

仓库包含可运行的 Electron/Vue 应用、共享 Markdown 词条核心、设置与文件仓储、Linux x64 AppImage 和测试 deb，以及 `branding/caretlex/` 下的正式 SVG 与 PNG。AppImage 和 deb 解包后的程序均通过真实窗口中的新词、同词复用、重复点击无写入、编辑、删除、源码保存和重开恢复冒烟。测试 deb 使用 `.invalid` 占位主页及维护者，不能发行；浏览器内 Logo 预览、deb 系统安装和部分原生对话框 UI 检查也尚未完成。命令、实测与边界记录在 [实施记录](ROADMAP.md)。

## 当前已定的边界

- 首版为阅读优先的 Electron 桌面应用：Vue 3、TypeScript、remark/GFM 阅读渲染、CodeMirror 6 源码编辑；提供多标签和亮暗主题。首版只打包 Linux x64 AppImage 与 deb。
- 词条脚注为 `[^w-lemma]`，定义体是一行**任意合法 JSON 值**。默认录入对象使用 `word`、`translation`、`example`，但协议不要求所有自定义词条都是对象。
- 首版 provider 只有手动录入；应用不自动词形还原，也不接在线或离线词典。只支持选择单个英文词，短语留待以后。
- 存词操作必须精确定位源码：除了目标引用和托管区块，不改变文档的其他字节。源码编辑由用户显式保存；遇到外部修改时停止覆盖并保留草稿。
- 词条 JSON 导出只处理当前文档的托管区块。外部 GFM 阅读器可把词条作为普通脚注显示，包括文末原始 JSON。
