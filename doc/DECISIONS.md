# 已确认决策与被替换的原方案

> 状态：已确认的产品决策。本文记录 2026-09-23 的产品访谈结论；实现与发行验收状态见 [路线图](ROADMAP.md)。出现冲突时，以 [协议](PROTOCOL.md)、[产品说明](PRODUCT.md) 和本表的**已确认决定**为准，不从早期方案中补回被取消的功能。

| 议题 | 已确认决定 | 被替换的提议及原因 |
| --- | --- | --- |
| 产品身份 | 面向英文阅读，简体中文界面；阅读与文档内存词优先。 | Typora 式通用编辑器不是首版目标。 |
| 桌面壳 | Electron，首版 Linux x64 AppImage 与 deb。 | 产品初稿建议 Tauri；用户明确选择 Electron。Windows/macOS 打包后续处理。 |
| 阅读解析 | `remark-parse + remark-gfm` 单管线，带源码位置；只解析和渲染，不全文回写 Markdown。 | [`markdown-it` 缺少完整行内源码位置](https://github.com/markdown-it/markdown-it/issues/195)；另加一套解析器易产生方言差异。[remark 使用的语法树位置](https://github.com/syntax-tree/unist#point)可支持定点写入验证。Milkdown 所见即所得会增加原文重排风险。 |
| 源码编辑 | CodeMirror 6，显式保存；多标签，未保存草稿切回阅读前须处理。 | 自动保存、500ms 防抖及首版所见即所得均不采用。 |
| 词条标签 | `[^w-lemma]`，Logo 同步改为 `[^w-]`。 | `[^w:lemma]` 的冒号在 GitHub 脚注链接中有[已报告的问题](https://github.com/github/cmark-gfm/issues/250)。 |
| 词条数据 | 标签是身份；定义可为任意单行合法 JSON 值。默认对象为 `word/translation/example`。 | 旧方案的 `gloss/source/added/count/status` 固定字段表已丢弃。默认翻译是中文，不是英英释义。 |
| 词形与 provider | 首版只有手动 provider。用户确认原型；字段来源可从选词上下文、手填或常量映射。 | Kaikki、Free Dictionary、MW、MDX、ECDICT 自动还原都不接入首版；未来如引入需重新审查授权、体积与条款。 |
| JSON 配置 | 设置页首版编辑完整 JSON 模板和来源映射，设置文件可移至用户指定同步目录；旧词条不自动迁移。 | 完整树状可视化 JSON 构建器写入未完成事项；设置不放进数据库。 |
| 相同 lemma | 多处引用共用定义；新位置加引用，已标记位置不重复，原句保持首次保存内容。 | 因无 `count` 字段，不再进行添加次数合并。 |
| 脚注与区块错误 | 区块外有效词条可读但不接管；坏 JSON 降级普通脚注；坏区块、重复定义阻止相关写入并保留原文。 | 不采用“下次保存自动覆盖用户手改坏内容”。 |
| 文件冲突 | 写前核对磁盘版本，有外部变化就停止覆盖并保留草稿。 | 不采用最后写入覆盖，也不在首版做自动三方合并。 |
| 导出 | 当前文档托管区块的完整 JSON 值，单行 lemma→值对象；提供按钮。 | CSV/TSV/Anki 取消；由 JSON 重建 Markdown 单词本留待以后。 |
| 外部阅读 | GFM 阅读器显示普通脚注编号和文末原始 JSON，可以接受；CaretLex 内改为下划线与悬停卡。 | 不为隐藏外部脚注而引入非标准 Markdown 或另一份导出文档。 |
| 视觉 | 保留脚注锚点 Logo 方向，四元素为 `[`, `^`, `w-`, `]`；A/B/C 比较，以 B 为定稿起点。 | 原视觉稿的 `w:` 随协议改为 `w-`，其余简洁几何方向保留。 |

## 不可被实现时临时放宽的约束

“只改目标引用和托管区块”是词条操作的验收条件。源码编辑模式下用户**明确编辑**的内容另当别论。阅读视图若无法把选中的可见单词唯一映射到源码，应禁用存词并提示，不能拿全文搜索的第一个同形词代替，也不能为方便实现而全文序列化。承诺支持的普通正文位置必须经过定位验证；未通过时不能宣称首版完成。

仓库在记录本决策时没有既有 commit 历史。日后提交前仍应检查当时的 commit message 格式，并遵从用户的仓库指令。
